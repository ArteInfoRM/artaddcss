# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities in Art Theme Add CSS privately to
helpdesk@tecnoacquisti.com. Include the module version, PrestaShop and PHP
versions, reproduction steps, and the potential impact. Do not post unpatched
security issues, customer data, or credentials in public GitHub issues.

If credentials are necessary, follow the instructions at
https://www.tecnoacquisti.com/it/content/19-come-inviare-le-tue-password.

## Supported releases

| Release line | PrestaShop / PHP requirements | Security support ends |
| --- | --- | --- |
| 1.1.x | Compatibility must be verified for the target shop. | Not formally defined for this historical module. |

## Security updates

Applicable security updates and compatibility instructions are communicated
with each advisory or support response. Commercial support and any update
entitlements remain separate from responsible vulnerability reporting.
